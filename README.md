# Prótein fyrir peninginn

Samanburður á verði og kaloríum fyrir 30 g prótein í 5.807 vörum úr Krónunni (gögn úr Krónu MCP, 26. október 2026).

- `docs/` er vefsíðan (GitHub Pages).
- `scripts/build.py` býr til `docs/data.json` úr `scripts/source-data.json` og bætir við tegund og merkingum um gölluð gögn.
